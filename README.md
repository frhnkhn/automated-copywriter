# Automated Copywriting & Tone Transformer

## Generative AI Project 2

An AI-powered copywriting application that automatically generates
marketing content based on product information, target platform,
tone, temperature and Top-P parameters.

## Features

- Dynamic prompt generation
- Product-specific marketing copy
- Platform-specific generation
- Multiple writing tones
- Temperature control
- Top-P control
- Pydantic input validation
- Command-line interface
- Local AI inference using Ollama
- Qwen3:8b model
- Asynchronous bulk generation
- Semaphore-based concurrency control
- JSON output
- CSV batch input

## Supported Platforms

- LinkedIn
- Instagram
- Email

## Supported Tones

- Professional
- Friendly
- Energetic
- Funny
- Persuasive
